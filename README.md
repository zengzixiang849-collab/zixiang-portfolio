# Zixiang Zeng Portfolio

A bilingual, static personal portfolio built for GitHub Pages. The visual system uses a pale-blue Hainan-light palette, an editorial profile sidebar, and a chronological content structure.

## Preview locally

Open `index.html` directly, or run a small static server in this folder:

```powershell
node server.cjs
```

Then visit `http://localhost:4173`.

## Deploy to GitHub Pages

1. Create a public GitHub repository and upload the contents of this folder.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Save and wait for the Pages URL to become available.

No build command or dependency installation is required.
